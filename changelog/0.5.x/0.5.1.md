# 0.5.1 — 2026-10-08

## Changed

- **Tool errors carry a request ID** — `content[]` ends with `request <id>` and error `data` carries `requestId` (mcp-ts-core 0.13.10).
- **Recovery hints are filled by the framework** — each declared error reason's hint is attached on the way to the client; the server no longer forwards it, and every hint reaches the client unchanged (0.13.10).
- **Error `data` is leaner** — it no longer carries stack traces (0.13.7), request-context fields (0.13.8), or `rootCause` (0.13.13).
- **Wrong-typed arguments are repaired before validation** — a JSON-stringified object for `scope` and an integer for `expression` (0.13.9); `null` at an optional key such as `precision` or `variable` is treated as omitted (0.13.14).
- **Argument-rejection hints name the field path**, e.g. `precision: …` (0.13.9).
- **A tool result that breaks its declared output schema fails as `-32603`** instead of `-32007` (0.13.8).
- **Logging** — the `ctx.log` mirror to the client honors `MCP_LOG_LEVEL` and masks sensitive fields (0.13.11); log `requestId` is always framework-generated, and a client's JSON-RPC id is logged as `jsonRpcId` (0.13.12).
- **Transport (MCP SDK, 0.13.9)** — a 2026-07-28 POST without `MCP-Protocol-Version` is refused with 400, and a JSON-RPC batch over 100 messages is refused.
- **Telemetry** — `OTEL_EXPORTER_OTLP_ENDPOINT` is honored (0.13.7); OTLP log export (`OTEL_EXPORTER_OTLP_LOGS_ENDPOINT`) and failed-call payload logging (`LOG_TOOL_FAILURE_PAYLOADS`) are opt-ins (0.13.8). `.env.example` documents the new logging and OTLP variables.
- **Docker image** — dependencies install in a `deps` stage on the build platform (0.13.10), musl-only packages are pruned (0.13.11), the base is Bun 1.4.2 (0.13.7), and `MCP_FORCE_CONSOLE_LOGGING` is no longer set.
- **`server.json`** — npm entries drop the `run start:*` arguments and set `runtimeHint: "npx"`; the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `http` (0.13.11).
- **Repo tooling** — `test:coverage` script; `.gitignore`, `.dockerignore`, and `.mcpbignore` sync (`.env*`, tests, logs, coverage); `dist/*.mcpb` excluded from the npm package; CodeQL analyzes `actions` and `javascript-typescript` under separate categories; framework skills, build and lint scripts, `CLAUDE.md`/`AGENTS.md`, and `changelog/template.md` resynced to 0.13.14.
- **Internal** — `MathService` methods no longer take `ctx`, and an unhandled `operation` throws `internalError`; tests aligned.

## Security

- **`config()` returns a fresh copy on every call** — it returned one shared object, so an expression that assigned into it changed what every later `config()` call returned, for the life of the process.
