# 0.5.3 — 2026-10-28

## Added

- **Agent Plugins manifests** provide root `plugin.json` and `mcp.json` alongside the existing client overlays.

## Changed

- **Desktop packaging** excludes development paths, node-gyp build output, and build-only dependency files; packaging checks validate those exclusions and the Agent Plugins manifests.
- **Development guidance** refreshes framework skills, simplifies hosted and local setup instructions, and collects bug-report environment details in one table.
- **Dependency age** changes from three days to one day.
- **Optional skill packaging** prepares npm and Docker paths for an author-managed root skill tree.

## Fixed

- **HTTP requests release shutdown-signal handlers after their responses finish**, through the framework upgrade ([mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)).
- **Desktop bundles keep MCP SDK runtime modules**, while the cleaner and packaging check remove agent documentation only at dependency package roots ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
