# 0.5.2 — 2026-10-25

## Changed

- **`calculate` formatting** uses the framework's Markdown escaper for expressions, results, result types, and scope names instead of code spans and fences; rendered values survive a CommonMark parse, and empty values render blank.
- **Error and recovery text** escapes Markdown syntax through the framework, preserving the diagnostic and recovery hint as literal text.
- **Hosted setup** documents separate Claude Code, Cline, Cursor, and Claude Desktop connection steps.
- **Desktop bundles** exclude source, scripts, documentation, and editor/workflow configuration.
- **Development tooling** refreshes framework references and distinguishes a vulnerable transitive copy from an unaffected direct dependency during audit classification.
- **Size-guard checks** use executing-thread CPU measurements for allocation-rejection assertions and separate the two full-size vector cases; format-size arithmetic is simplified without changing its result.
